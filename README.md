# covariance_ar
Ковариационный метод оценки АР-модели
Интерактивная программа на Python для исследования ковариационного метода оценки параметров авторегрессионной (AR) модели и построения спектральной оценки комплексных сигналов на фоне шума.
Возможности
- Генерация комплексного двухтонального сигнала с различными амплитудами.
- Генерация комплексного линейно-частотно-модулированного (ЛЧМ) сигнала.
- Добавление комплексного белого гауссовского шума.
- Регулировка отношения сигнал/шум (ОСШ) от −10 до 40 дБ.
- Регулировка числа отсчётов N и порядка модели p.
- Вычисление коэффициентов AR ковариационным методом на основе метода наименьших квадратов.
- Построение спектральной оценки AR-модели.
- Динамическое обновление графиков при изменении параметров.
Требования
- Python 3.10 или новее (рекомендуется).
- Библиотеки numpy, matplotlib, scipy.
Установка
1. Установите Python: https://www.python.org/
2. Откройте терминал в папке с программой.
3. Установите библиотеки:
pip install numpy matplotlib scipy
Запуск
Выполните команду:
python covariance_ar_interactive.py
После запуска откроется интерактивное окно с графиками и элементами управления.
Параметры программы
Параметр	Диапазон	Описание
ОСШ	−10…40 дБ	Отношение мощности полезного сигнала к мощности шума
Порядок AR-модели p	2…100	Количество коэффициентов линейного предсказания
Число отсчётов N	128…2048	Длина наблюдаемой последовательности

Кнопка «Новый шум» формирует новую реализацию шумовой последовательности при текущих настройках.
Теоретическая основа
Модель линейного предсказания:
\[
\hat{x}[n] = -\sum_{k=1}^{p}a[k]x[n-k].
\]
Ошибка предсказания:
\[
e_p[n] = x[n] + \sum_{k=1}^{p}a[k]x[n-k].
\]
Коэффициенты модели определяются минимизацией суммарной квадратичной ошибки:
\[
J = \sum_{n=p}^{N-1}|e_p[n]|^2.
\]
Формируется матрица регрессоров X, после чего решается задача наименьших квадратов:
\[
\mathbf{a}=\arg\min_{\mathbf{a}}\|\mathbf{X}\mathbf{a}+\mathbf{y}\|_2^2.
\]
Решение вычисляется с помощью numpy.linalg.lstsq, без рекурсивного алгоритма Левинсона.

АР-спектральная оценка:
\[
P_{AR}(f)=
\frac{\sigma_e^2}
{\left|1+\sum_{k=1}^{p}a[k]e^{-j2\pi fk/f_s}\right|^2},
\]
где p — порядок модели, a[k] — коэффициенты AR, \(\sigma_e^2\) — мощность ошибки предсказания, а \(f_s\) — частота дискретизации.
Интерпретация результатов
- При низком ОСШ шум заметно влияет на спектральную оценку.
- При увеличении ОСШ полезные спектральные компоненты проявляются отчетливее.
- Порядок модели p влияет на разрешение спектральных пиков и характер оценки.
- Число отсчётов N влияет на статистическую точность.
Для двухтонального сигнала ожидаются два спектральных пика. У ЛЧМ-сигнала частота меняется во времени, поэтому его спектральная структура отличается от двухтонального сигнала.

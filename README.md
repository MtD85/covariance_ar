
# Ковариационный метод оценки АР-модели

Интерактивная программа на Python для исследования ковариационного метода оценки параметров авторегрессионной (AR) модели и построения спектральной оценки комплексных сигналов на фоне шума.

## Возможности

- Генерация комплексного двухтонального сигнала с различными амплитудами.
- Генерация комплексного линейно-частотно-модулированного (ЛЧМ) сигнала.
- Добавление комплексного белого гауссовского шума.
- Регулировка отношения сигнал/шум (ОСШ) от −10 до 40 дБ.
- Регулировка числа отсчётов сигнала `N`.
- Регулировка порядка авторегрессионной модели `p`.
- Вычисление коэффициентов AR ковариационным методом на основе метода наименьших квадратов.
- Построение спектральной оценки AR-модели.
- Динамическое обновление графиков при изменении параметров.

## Используемые технологии

- Python 3.10+
- NumPy
- Matplotlib
- SciPy

## Установка

Клонируйте репозиторий:

Перейдите в директорию проекта:

```bash
cd covariance_ar
```

Установите необходимые библиотеки:

```bash
pip install numpy matplotlib scipy
```

## Запуск программы

Запустите программу командой:

```bash
python covariance_ar_interactive.py
```

После запуска откроется интерактивное окно с графиками и элементами управления.

## Параметры программы

| Параметр | Диапазон | Описание |
|---|---|---|
| ОСШ | −10...40 дБ | Отношение мощности сигнала к мощности шума |
| Порядок AR-модели `p` | 2...100 | Количество коэффициентов линейного предсказания |
| Число отсчётов `N` | 128...2048 | Длина наблюдаемой последовательности |
| Тип сигнала | Два тона / ЛЧМ | Выбор моделируемого комплексного сигнала |

Кнопка **«Новый шум»** позволяет сформировать новую реализацию шумовой последовательности при текущих настройках.

## Теоретическая основа

В программе используется модель линейного предсказания:

$$
\hat{x}[n] = -\sum_{k=1}^{p}a[k]x[n-k].
$$

Ошибка линейного предсказания:

$$
e_p[n] = x[n] + \sum_{k=1}^{p}a[k]x[n-k].
$$

Коэффициенты AR-модели определяются минимизацией суммарной квадратичной ошибки:

$$
J = \sum_{n=p}^{N-1}|e_p[n]|^2.
$$

Для вычисления коэффициентов формируется матрица регрессоров `X`, после чего решается задача наименьших квадратов:

$$
\mathbf{a}=\arg\min_{\mathbf{a}}\|\mathbf{X}\mathbf{a}+\mathbf{y}\|_2^2.
$$

Решение вычисляется с помощью `numpy.linalg.lstsq`, без рекурсивного алгоритма Левинсона.

АР-спектральная оценка определяется выражением:

$$
P_{AR}(f)=
\frac{\sigma_e^2}
{\left|1+\sum_{k=1}^{p}a[k]e^{-j2\pi fk/f_s}\right|^2},
$$

где:

- `p` — порядок AR-модели;
- `a[k]` — коэффициенты линейного предсказания;
- $\sigma_e^2$ — мощность ошибки предсказания;
- $f_s$ — частота дискретизации.

## Интерпретация результатов

- При низком ОСШ шум существенно влияет на спектральную оценку.
- При увеличении ОСШ полезные спектральные компоненты проявляются отчётливее.
- Порядок модели `p` влияет на разрешение спектральных пиков.
- Число отсчётов `N` влияет на статистическую точность оценки.

Для двухтонального сигнала ожидаются два спектральных пика. Для ЛЧМ-сигнала частота изменяется во времени.
